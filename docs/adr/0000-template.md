# ADR template

Copy this file to `NNNN-kebab-case-title.md` (next free number,
imperative verb phrase). Keep it short: the decision and its
consequences matter, not the process. Do not rewrite an accepted ADR;
supersede it with a new one and update the old one's Status.

```markdown
# ADR-NNNN: Title

- Status: Proposed | Accepted | Superseded by ADR-MMMM
- Date: YYYY-MM-DD

## Context

What problem forces a decision? What constraints apply
(never modifying the source world, game compatibility, output-contract
stability, ...)?

## Decision

What we do, concretely (rules, flags, file formats, defaults).

## Consequences

What this buys, what it costs, and what is explicitly out of scope.
```
