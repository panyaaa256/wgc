# バージョンの参照表

実装先: `core` の定数。数値は下の名前で定義し、テストで実際のワールドと突き合わせる。

タグの型や有無で判断できるものは、DataVersion で分岐しない。

| 定数名 | バージョン | DataVersion | 用途 |
|---|---|---|---|
| `DV_CHUNK_ROOT` | 21w43a | 2844 | チャンク NBT の `Level` がなくなり、フィールドがルート直下に移った |
| `DV_1_21_5` | 1.21.5 | 4325 | T-2（Paper の不具合）の対象の下限 |
| `DV_SESSION_LOCK_OS` | 1.16 前後（要調査） | 要調査 | これ以降、`session.lock` に OS のロックがかかる |
| `DV_MAX_KNOWN` | — | 要調査 | ツールが保存形式を把握している最新の値。リリースごとに更新する |

- 1.9（169）より前のチャンクと `level.dat` は、DataVersion を持たないことがある。その場合は最も古い形式として扱う。
- `level.dat` の `Data.DataVersion` が `DV_MAX_KNOWN` より大きいワールドは「知らないバージョン」とする（trust の T-4）。
