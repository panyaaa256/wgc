# バージョンの参照表

他の文書は、下の表の名前でバージョンを指す。各値は、実際のワールドのデータと突き合わせて確かめる。

タグの型や有無で判断できるものは、DataVersion で分岐しない。

| 名前 | バージョン | DataVersion | 用途 |
|---|---|---|---|
| `DV_SESSION_LOCK_OS` | 20w14a（1.16 のスナップショット） | 2524 | これ以降、`session.lock` に OS のロックがかかる |
| `DV_CHUNK_ROOT` | 21w43a | 2844 | チャンク NBT の `Level` がなくなり、フィールドがルート直下に移った |
| `DV_TICKETS` | 1.21.5 のスナップショット | 4297 | 強制読み込みチャンクの保存が `Forced` から `tickets` に変わった |
| `DV_1_21_5` | 1.21.5 | 4325 | T-2（Paper の不具合）の対象の下限 |
| `DV_GAMERULE_REGISTRY` | 25w44a の直前 | 4658 | `level.dat` の `GameRules` が `game_rules` になり、キーと値の形式が変わった |
| `DV_FILES_26_1` | 26.1 のスナップショット | 4772 | ファイルの配置の変更（ディメンション、プレイヤーデータ、`level.dat` からの分離、`data/` の名前空間化） |
| `DV_MAX_KNOWN` | 26.3 | 5023 | ツールが保存形式を把握している最新の値。リリースごとに更新する |

参考: 1.21.11 = 4671、26.1 = 4786。

- 1.9（169）より前のチャンクと `level.dat` は、DataVersion を持たないことがある。その場合は最も古い形式として扱う。
- `level.dat` の `Data.DataVersion` が `DV_MAX_KNOWN` より大きいワールドは「知らないバージョン」とする（trust の T-4）。
