# バージョンの参照表

> 前提: なし。P2、P3、P5、P7 から参照する。
> 実装先: `wgc-core` の定数（例: `core::versions`）。数値をコードに直接書かず、ここの名前で定義する。

## 方針

- バージョンは `level.dat` の `Data.DataVersion`（ワールドの現在のバージョン）と、各チャンクの `DataVersion` で判断する。
- **タグの型や有無で判断できるものは、DataVersion ではなくそちらで判断する**（例: プレイヤーの `Dimension` が Int か String か）。DataVersion による分岐は、それ以外の方法がない場合だけにする。
- 下の数値は、テストで実際のワールドと突き合わせて確認する。確認していない値には「要確認」を付ける。

## ツールが知らないバージョン

- `level.dat` の `Data.DataVersion` が `DV_MAX_KNOWN` より大きい場合、そのワールドは「ツールが知らないバージョン」とする。
- 知らないバージョンでは、保存形式が変わっている可能性がある項目（ゲームルール、強制読み込みチャンク、プレイヤーデータの場所）を「確認できない」とする。扱いは [trust.md](trust.md) の T-4 と「判定の使い方」。
- `Data.DataVersion` がない（1.9 より前の）ワールドは、「古いバージョン」として扱う。保存形式は最も古い形式を前提にする。
