# 共通の規約

## 座標

Minecraft の形式に従う。

- チャンクの位置を1つの Long に詰めた値は、下位 32 ビットが x、上位 32 ビットが z（どちらも符号付き）。構造物の参照、強制読み込みチャンク、`chunk_pos` で使われる。
- チャンク `(x, z)` を含むリージョンは `(x >> 5, z >> 5)`、リージョン内のインデックスは `(x & 31) + (z & 31) * 32`（0〜1023）。

## ディメンション ID

- `<ns>:<name>` の形。`overworld` のように名前空間を省いたものは `minecraft:` を補う。形の不正な ID は受け付けない。
- 表示では、受け付ける最も短い形を使う（`minecraft:the_nether` → `the_nether`）。

## 確認の ID

`--force` で無視できる確認は、表示でも JSON でも `T-1`〜`T-5`、`L-1` の形で示す。意味は trust.md と lock.md が定める。

## 決定性

- 同じ入力からは、並列に処理しても同じ内容・同じ順序の結果（判定、表示、JSON）を出す。

## 警告

処理は警告があっても続く。警告の種類は次のとおり。

| 警告 | 出す場面 |
|---|---|
| ロックを取れなかった | scan と見積もりで、ロックを取れずに続行したとき |
| ロックなしで続行した | L-1 を `--force` で無視したとき |
| 起動中かどうかを検出できない | ワールドが 20w14a（versions.md の `DV_SESSION_LOCK_OS`）より古いとき |
| 所有者を合わせられない | 出力のファイルの所有者を元に合わせられないとき（一度だけ） |
| シンボリックリンクを辿った | 出力でリンクの実体を書いたとき（パスつき） |
| 特殊なファイルを飛ばした | 通常のファイルとディレクトリ以外、またはリンク先のないリンクを出力しなかったとき（パスつき） |
| 確認を無視した | `--force` で確認を無視したとき（確認の ID つき） |

## 進捗と中断

- 長い処理は、読み込み（リージョン三つ組の数）、書き出し（元のワールドのファイルの数）、検証（書いたファイルの数）の段階ごとに、終わった数と全体の数を報告する。終わった数は減らない。
- 中断（Ctrl-C）を受けたら、処理中の単位（リージョン三つ組、または1つのファイル）を終えた時点で止まる。中断した処理は成功として扱わない。

## エラー

- I/O の失敗は、対象のパスを示す。
- 終了コードは、失敗の区別から決まる（cli.md「終了コード」）。

## JSON

JSON の共通の規則（キーの書き方、パスの表し方、UTF-8 でないパス）は docs/json.md が定める。

## 受け入れ条件

- 負の座標を含む Long から、チャンクの位置を正しく戻せる。インデックス 1024 以上は存在しない。チャンクの位置とリージョン内のインデックスが往復する。
- ディメンション ID の省略形を補い、形の不正な ID を拒否する。表示に使う最も短い形を読み込むと、元の ID に戻る。
- 確認の ID が `T-1` の形で表示され、JSON に出る。
